## 3. 新增指令五步法（按本仓库结构）

> 原则：**只改 SpinalHDL 源码，重新生成网表**。永远不要去改 13.6 万行的 `mycpu_top.v`。

### 第 1 步：定义指令编码

文件：`src/vivado_cannot/src/constants/LoongArch.scala`

仿照已有条目，在 `object LoongArch` 里加一行：

```scala
val MYINST = MakeMaskedLiteral("00000000000100000" + Rk() + Rj() + Rd())  // 以考卷给定编码为准
```

- `Rk()/Rj()/Rd()` 是 5 位通配（`-----`），`Bits(n)` 是 n 位通配；其余位写死 0/1。
- 空格会被自动去掉，凑满 32 位即可。
- 字段含义（`InstructionParser.scala`）：`rd=inst[4:0]`，`rj=inst[9:5]`，`rk/sa=inst[14:10]`，
  `imm12=inst[21:10]`，`imm20=inst[24:5]`。

### 第 2 步：（仅新运算需要）扩展 ALU 操作枚举

文件：`src/vivado_cannot/src/constants/enum/ALUOpType.scala`

```scala
val MYCLO = newElement()
```

现有可用枚举（能复用就复用，**复用则跳过第 2、3 步**）：
`ADD/ADDU/SUB/SUBU/AND/OR/XOR/NOR/SLT/SLTU/SLL/SRL/SRA/LU12I/PCADDI/PCADDU12I/CPUCFG`

### 第 3 步：（仅新运算需要）实现 ALU 运算

文件：`src/vivado_cannot/src/pipeline/exe/ALU.scala`

在 `switch(op)` 里加分支：

```scala
is(MYCLO) {
  result := /* 用 src1, src2, sa 表达的组合逻辑 */
}
```

- `src1`：rj 的值（`useRj=True` 时），否则是 0 / PC（取决于 aluOp 特例）。
- `src2`：rk 的值（`useRk=True` 时），否则是**符号扩展 imm12**（`immExtendType=ZERO` 时零扩展）。
- `sa`：`useRk=True` 时为 rk 值低 5 位，否则为 `inst[14:10]`。

### 第 4 步：挂译码

文件：`src/vivado_cannot/src/pipeline/decode/DecoderArrayPlugin.scala`，
函数 `BuildLoongArch` 末尾的 `addAll(...)` 区域（约 346–513 行）。

直接套下面第 4 节的模板。

## 4. 三大类指令译码模板（直接抄改）

以下代码都写在 `BuildLoongArch` 里。译码动作包已定义好：

| 动作包             | 含义                           |
| ------------------ | ------------------------------ |
| `reg2R1WActions` | 读 rj、rk，写 rd               |
| `reg1R1WActions` | 读 rj，写 rd（src2 走 imm12）  |
| `reg1RActions`   | 只读 rj                        |
| `reg1WActions`   | 只写 rd                        |
| `useUnsignedImm` | imm12 零扩展（默认是符号扩展） |

### 4.1 计算类

```scala
// (a) 3 寄存器型（add.w 型）：rd = rj OP rk
LoongArch.MYOP -> (reg2R1WActions ++ Seq(aluOp -> ALUOpType.MYOP))

// (b) 立即数型（addi.w 型）：rd = rj OP sext(imm12)
LoongArch.MYOPI -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.MYOP))
// 逻辑运算类立即数记得换零扩展：
LoongArch.MYOPI -> (useUnsignedImm ++ reg1R1WActions ++ Seq(aluOp -> ALUOpType.MYOP))

// (c) 移位立即数型（slli.w 型）：aluOp 复用 SLL/SRL/SRA，sa 自动取 inst[14:10]
LoongArch.MYSLLI -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.SLL))

// (d) 单源型（clo.w 型）：rd = f(rj)
LoongArch.MYCLO -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.MYCLO))

// (e) 乘除型：走 MDU，复用 FUType.MUL/MULH/DIV/MOD + signed 标志
LoongArch.MYMUL -> (reg2R1WActions ++ Seq(fuType -> FUType.MUL, signed -> True))
```

### 4.2 分支类

```scala
// (a) 双源比较分支（beq 型）：比较 rj 与 **rd**（注意：不是 rk！），偏移 si16<<2
val branchActions = Seq(fuType -> FUType.CMP, isBranch -> True, useRd -> True)
LoongArch.MYBEQ -> (branchActions ++ reg1RActions ++ Seq(cmpOp -> CompareOpType.EQ))
// cmpOp 可选：EQ/NE/LT/GE/LTU/GEU（还有 LE/GT/LEU/GTU 可用）

// (b) 单源与零比较分支（beqz 型）：只读 rj
LoongArch.MYBEQZ -> (Seq(fuType -> FUType.CMP, isBranch -> True, useRj -> True,
                         cmpOp -> CompareOpType.EQZ))
// 单源 cmpOp 可选：EQZ/NEZ/LTZ/GEZ/LEZ/GTZ
```

- 分支目标 = `pc + sext(inst[25:10] << 2)`（BRU.scala 已写死这个格式，考卷指令若同为 si16 偏移则零改动）。
- 若考卷分支指令偏移字段**不是** `inst[25:10]<<2`，需改 `src/pipeline/exe/BRU.scala` 的 `branchOffset`。
- 分支自动进入 unique retire + 误预测冲刷，无需额外处理。

### 4.3 访存类

```scala
// (a) load（ld.w 型）：rd = Mem[rj + sext(si12)]
val memActions = Seq[(Stageable[_ <: Data], Any)](fuType -> FUType.LSU)
val loadActions = memActions ++ reg1R1WActions ++ Seq(isLoad -> True)
LoongArch.MYLD -> (loadActions ++ Seq(lsType -> LoadStoreType.WORD))
// lsType 可选：BYTE/BYTE_U/HALF/HALF_U/WORD

// (b) store（st.w 型）：Mem[rj + sext(si12)] = **rd**（注意：store 数据读的是 rd 字段！）
val storeActions = memActions ++ reg1RActions ++ Seq(isStore -> True, useRd -> True)
LoongArch.MYST -> (storeActions ++ Seq(lsType -> LoadStoreType.WORD))
```

- 地址偏移默认取 `inst[21:10]` 符号扩展（si12），在 `MemIssueQueuePlugin.scala:42` 写死。
- 若考卷访存指令是 **si14<<2** 格式（ll.w/sc.w 型），参照同文件 43–45 行的 LL/SC 特例加一条 `when`。
- 非对齐检查（ALE 例外）由 LSU 按 lsType 自动处理。

## 5. 坑位清单（每条都是踩过的/代码里写死的）

1. **分支第二操作数是 rd 不是 rk**：`beq rj, rd, off`。译码要写 `useRd -> True`，
   比较器 src2 才会取 rd 寄存器值（IntExecutePlugin.scala:235）。
2. **store 的数据寄存器是 rd**：译码 `useRd -> True`，不是 useRk。
3. **立即数默认符号扩展**：逻辑类立即数指令必须加 `useUnsignedImm`。
4. **rd==r0 时硬件自动取消写回**（`doRegWrite := isRegWrite & (wbAddr =/= 0)`），不用管。
5. **非法指令不需要判**：没有匹配编码时自动报 INE 例外；新指令加了编码即合法。
6. **普通计算/分支/访存不用动 uniqueRetire / flushState**——那是 CSR/TLB/CACOP/ERTN 类才需要的。
7. 译码重复添加同一编码只会打印 Warning（先到先得），**改编码时确认没有和旧条目掩码重叠**。
8. `RDCNTVH`/`RDCNTVL` 这类 rd==0 转读 rj 的特殊逻辑只属 Timer，新指令别去碰 Epilogue。
9. 若新指令要读 **si20 型立即数**（lu12i.w 型），参照 `ALUOpType.LU12I/PCADDI/PCADDU12I` 在
   `IntExecutePlugin.scala:189-221` 的 src1/src2 特例写法（用 `fields.signExtendImm20_12` 等）。
10. 生成网表覆盖 `src/mycpu/mycpu_top.v` 后，Vivado 工程直接重综合即可；Xilinx IP（multiplier.xci）不变。

## 7. 完整示例：实现 CLO.W（前导 1 计数，rd = clz 的补）

假设考卷要求：`clo.w rd, rj`，编码 `0000000000000000000100 rj rd`（示例编码，以考卷为准）。

**① LoongArch.scala** 加：

```scala
val CLO_W = MakeMaskedLiteral("0000000000000000000100" + Rj() + Rd())
```

**② ALUOpType.scala** 加（文件里本来就有注释掉的 `// val CLO, CLZ` 提示位）：

```scala
val CLO = newElement()
```

**③ ALU.scala** 的 `switch(op)` 加：

```scala
is(CLO) {
  val count = U(32, 6 bits)
  val seen0 = False
  for (i <- 31 downto 0) {
    when(!seen0 && !src1(i)) {
      count := 31 - i
      seen0 := True
    }
  }
  result := count.resized
}
```

（clz/cto/ctz 同理：`!src1(i)` 换 `src1(i)`、循环方向换 `0 to 31` 即可。）

**④ DecoderArrayPlugin.scala** 的 `BuildLoongArch` 加：

```scala
LoongArch.CLO_W -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.CLO))
```

**⑤** 跑 `rebuild_netlist.bat` → 写测试汇编 → 仿真验证。
