## 第二部分 · 架构速览（知道这些就够了）

NOP-Core 是**乱序超标量** LoongArch32r 核（SpinalHDL 1.8.1 生成）：

```
取指(Fetch/BTB/RAS/ICache) → 取指缓冲 → 译码×3(DecoderArray+重命名)
  → 派发到 4 个发射队列：IntIQ×2(纯ALU) / IntIQ×1(ALU+BRU+CSR+Timer) / MulDivIQ / MemIQ
  → 发射(乱序) → 执行(ALU/Comparator+BRU/MDU/LSU) → ROB(提交, 精确例外)
```

对新指令而言，**你只需要理解"译码 → 发射队列 → 执行单元"这一条线**：

| 新指令类型 | fuType | 进入的队列 | 执行者 |
|---|---|---|---|
| 算术/逻辑/移位（默认） | `FUType.ALU` | IntIQ | `ALU.scala`（组合逻辑，单拍） |
| 分支比较 | `FUType.CMP` | IntIQ(BRU 口) | `Comparator.scala` + `BRU.scala` |
| 乘除 | `FUType.MUL/MULH/DIV/MOD` | MulDivIQ | `MulDivExecutePlugin.scala` |
| 访存 | `FUType.LSU` | MemIQ | MemExecute/DCache/StoreBuffer |
| 无执行需求（如 barrier 类） | `FUType.NONE` | 直接提交 | — |

**冒险/旁路/写回全自动**：译码时声明 `useRj/useRk/useRd/isRegWrite` 后，
记分牌（PRF busy 表）、旁路网络、ROB 写回全部自动生效，**新指令不需要碰任何冒险逻辑**。
这就是为什么在本核上加一条普通指令只需要改译码表 +（可选）ALU。

### 字段切分（`InstructionParser.scala`，全部可用字段）

| 字段 | 位段 | 说明 |
|---|---|---|
| `rd` | inst[4:0] | 目的寄存器（分支/访存里常被借作源寄存器，见坑位） |
| `rj` | inst[9:5] | 源寄存器 1 |
| `rk` | inst[14:10] | 源寄存器 2 |
| `sa` | inst[14:10] | 移位量（与 rk 同位段） |
| `imm12` / `signExtendImm12` / `zeroExtendImm12` | inst[21:10] | 12 位立即数（访存偏移、立即数运算） |
| `imm20` / `signExtendImm20_2` / `signExtendImm20_12` | inst[24:5] | 20 位立即数（lu12i/pcadd 类） |
| `csrAddr` | inst[23:10] | CSR 地址 |

执行级 src1/src2/sa 的真实来源选择逻辑在 `IntExecutePlugin.scala:182–224`：

- `src1 = useRj ? rj值 : (LU12I→0, PCADDI/PCADDU12I→pc)` 
- `src2 = useRk ? rk值 : (默认 imm12 扩展值；LU12I/PCADDx 走 imm20 特例)`
- `sa = useRk ? rk值[4:0] : inst[14:10]`

**推论**：想让 src2 用上新的立即数格式（如 si14、si16），在 189–221 行那两个
`switch(issSlot.uop.aluOp)` 里照 LU12I 的样子加特例即可。

### 访存地址偏移（`MemIssueQueuePlugin.scala:42–45`）

- 默认：`immField = sext(inst[21:10])`（si12，覆盖 ld/st.b/h/w）
- LL/SC 特例：`immField = sext(inst[23:10] << 2)`（si14<<2）
- 新访存指令若用 si14<<2 格式：照 `isSC || isLL` 那个 `when` 加一条即可。

### 分支目标（`BRU.scala:37–46`）

- 条件分支：`pc + sext(inst[25:10] << 2)`（si16<<2）
- B/BL：`pc + sext({inst[9:0], inst[25:10]} << 2)`（si26<<2）
- JIRL：`rj + sext(inst[25:10] << 2)`
- 新分支指令若偏移格式不同，改 `branchOffset` 的拼接即可。

## 第三部分 · 新增指令五步法（精确到行）

### Step 1 定义编码 —— `src/vivado_cannot/src/constants/LoongArch.scala`

```scala
val MYINST = MakeMaskedLiteral("00000000000100000" + Rk() + Rj() + Rd())
```

- `Rk()/Rj()/Rd()` = 5 位通配；`Bits(n)` = n 位通配；固定位写 0/1；空格任意。
- **编码以考卷为准**。写完后数一遍：去掉空格必须恰好 32 位（多了少了 sbt 会 assert）。
- 与现有编码掩码重叠时，译码器打印 Warning 且**先添加的生效**——加完注意 elaborate 日志。

### Step 2 （仅全新运算）加枚举 —— `constants/enum/ALUOpType.scala`

```scala
val MYCLO = newElement()
```

能复用现有枚举就不要加。现有清单：
`ADD ADDU SUB SUBU AND OR XOR NOR SLT SLTU SLL SRL SRA LU12I PCADDI PCADDU12I CPUCFG`。

### Step 3 （仅全新运算）实现运算 —— `pipeline/exe/ALU.scala`

`switch(op)` 内加分支。操作数只有三个：`src1` `src2` `sa`（含义见第二部分）。
SpinalHDL 常用写法速查：

```scala
result := src1 + src2                    // 加减
result := src1 & src2                    // 逻辑
result := src1 |<< sa                    // 逻辑左移（|>> 右移）
result := (src1.asSInt >> sa).asUInt     // 算术右移
result := (src1.asSInt < src2.asSInt).asUInt.resized   // 有符号比较置 1
result := src1(15 downto 0) @@ src2(15 downto 0)       // 拼接
val tmp = UInt(32 bits); tmp := ...; result := tmp     // 临时量
```

### Step 4 挂译码 —— `pipeline/decode/DecoderArrayPlugin.scala` 的 `BuildLoongArch`（346–513 行）

预定义动作包（367–372 行）：

| 包 | 内容 |
|---|---|
| `reg1WActions` | isRegWrite |
| `reg1RActions` | useRj |
| `reg1R1WActions` | useRj + isRegWrite |
| `reg2RActions` | useRj + useRk |
| `reg2R1WActions` | useRj + useRk + isRegWrite |
| `useUnsignedImm` | immExtendType = ZERO（默认 SIGN） |

#### 4.1 计算类模板

```scala
// 3 寄存器型 rd = rj OP rk（add.w 型）
LoongArch.MYOP -> (reg2R1WActions ++ Seq(aluOp -> ALUOpType.MYOP))

// 立即数型 rd = rj OP sext(si12)（addi.w 型）
LoongArch.MYOPI -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.MYOP))
// 逻辑立即数型（andi 型，零扩展）
LoongArch.MYOPI -> (useUnsignedImm ++ reg1R1WActions ++ Seq(aluOp -> ALUOpType.MYOP))

// 移位立即数型（slli.w 型；复用 SLL/SRL/SRA，sa 自动取 inst[14:10]）
LoongArch.MYSLLI -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.SLL))

// 单源型 rd = f(rj)（clo.w 型）
LoongArch.MYCLO -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.MYCLO))

// 乘除型（走 MDU，signed 控制有无符号）
LoongArch.MYMUL -> (reg2R1WActions ++ Seq(fuType -> FUType.MUL, signed -> True))
//   FUType 可选：MUL(低32位) MULH(高32位) DIV MOD
```

#### 4.2 分支类模板

```scala
// 双源比较分支（beq 型）：比较 rj 与 rd（★不是 rk），目标 pc+sext(si16<<2)
LoongArch.MYBEQ -> (Seq(fuType -> FUType.CMP, isBranch -> True,
                        useRj -> True, useRd -> True,
                        cmpOp -> CompareOpType.EQ))
// cmpOp 双源可选：EQ NE LT GE LTU GEU LE GT LEU GTU

// 单源与零比较分支（beqz 型）：只读 rj
LoongArch.MYBEQZ -> (Seq(fuType -> FUType.CMP, isBranch -> True,
                         useRj -> True, cmpOp -> CompareOpType.EQZ))
// cmpOp 单源可选：EQZ NEZ LTZ GEZ LEZ GTZ
```

- 比较器 src2 的选择：`useRd=True` → rd 寄存器值；否则 imm12 扩展值
  （`IntExecutePlugin.scala:235`）。所以"与立即数比较分支"也能零改动表达。
- 分支自动获得：误预测冲刷、unique retire、预测器更新。**无需任何额外动作**。

#### 4.3 访存类模板

```scala
val memActions = Seq[(Stageable[_ <: Data], Any)](fuType -> FUType.LSU)

// load：rd = Mem[rj + sext(si12)]（ld.w 型）
LoongArch.MYLD -> (memActions ++ reg1R1WActions ++
                   Seq(isLoad -> True, lsType -> LoadStoreType.WORD))
// lsType：BYTE BYTE_U HALF HALF_U WORD（符号/零扩展、对齐例外自动处理）

// store：Mem[rj + sext(si12)] = rd（★store 数据读 rd 字段）
LoongArch.MYST -> (memActions ++ reg1RActions ++
                   Seq(isStore -> True, useRd -> True, lsType -> LoadStoreType.WORD))
```

## 第四部分 · 三个端到端完整示例

### 示例 A：计算类 —— CLO.W（前导 1 计数）

假设考卷：`clo.w rd, rj`；编码 `0000000000000000000100 rj rd`（示例，以考卷为准）。

**① `constants/LoongArch.scala`**（跟在 CPUCFG 定义附近加）：

```scala
val CLO_W = MakeMaskedLiteral("0000000000000000000100" + Rj() + Rd())
```

**② `constants/enum/ALUOpType.scala`**：

```scala
val CLO = newElement()
```

**③ `pipeline/exe/ALU.scala`**（`switch(op)` 内）：

```scala
is(CLO) {
  val count = U(32, 6 bits)
  val seen0 = False
  for (i <- 31 downto 0) {
    when(!seen0 && !src1(i)) {
      count := 31 - i
      seen0 := True
    }
  }
  result := count.resized
}
```

变体：CLZ 把 `!src1(i)` 换 `src1(i)`；CTO/CTZ 把循环换成 `0 to 31`（i 从低位起，命中时 `count := i`）。

**④ `DecoderArrayPlugin.scala` 的 BuildLoongArch**：

```scala
LoongArch.CLO_W -> (reg1R1WActions ++ Seq(aluOp -> ALUOpType.CLO))
```

**⑤⑥** 重建 + 测试。测试宏（func 框架风格）：

```asm
#define TEST_CLO_W(in_a, ref) \
    LI (t0, in_a); \
    LI (v1, ref); \
    NOP4; \
    clo.w v0, t0; \
    NOP4; \
    bne v0, v1, inst_error; \
    NOP4
```

### 示例 B：分支类 —— BEQZ（等于零跳转）

假设考卷：`beqz rj, offs16`；编码 `010110 + si16 + rj + 00000`（示例）——
注意这个编码与 BEQ 的区别只在 rd 字段恒 0。为安全起见给独立编码空间，以考卷为准。

**① 编码**：

```scala
val BEQZ = MakeMaskedLiteral("011100" + Bits(16) + Rj() + Rd())   // 若考卷占 rd 字段则用 Rd() 占位
```

**②③** 不需要：Comparator 已内置 EQZ/NEZ/LTZ/GEZ/LEZ/GTZ。

**④ 译码**：

```scala
LoongArch.BEQZ -> (Seq(fuType -> FUType.CMP, isBranch -> True,
                       useRj -> True, cmpOp -> CompareOpType.EQZ))
```

目标地址自动走 `pc + sext(inst[25:10] << 2)`，与 beq 同格式，BRU 零改动。

**测试要点**：正/负偏移都要测；跳与不跳都要测；连续两条 beqz（背靠背）测预测恢复。

### 示例 C：访存类 —— 假设 si14 偏移的 LDX.W

假设考卷：`ldx.w rd, rj, si14`（偏移 = sext(si14)<<2，字段 inst[23:10]），编码示例
`0010100011 + si14 + rj + rd`。

**① 编码**：

```scala
val LDX_W = MakeMaskedLiteral("0010100011" + Bits(14) + Rj() + Rd())
```

**②③** 不需要新 ALU 枚举（LSU 自己算地址）。

**④ 译码**：

```scala
LoongArch.LDX_W -> (memActions ++ reg1R1WActions ++
                    Seq(isLoad -> True, lsType -> LoadStoreType.WORD))
```

**④b 偏移格式**（`pipeline/mem/MemIssueQueuePlugin.scala` 42–45 行处）：
在现有 `when(slot.uop.isSC || slot.uop.isLL)` 后面照抄一个条件。最稳妥的判据是直接判编码：

```scala
when(uop.inst(31 downto 24) === B"00101000" && uop.inst(25 downto 24) === U(3)) {
  // 以考卷编码实际位段为准；等价写法：和 LL/SC 共用 si14<<2 逻辑
  slot.uop.immField := (uop.inst(23 downto 10) ## U(0x0, 2 bits)).asSInt.resize(32 bits).asBits
}
```

> 更简单：若与 LL/SC 同格式，直接把条件改成
> `when(slot.uop.isSC || slot.uop.isLL || <新指令判据>)`。
> 判据用译码器里新增一个 Stageable 最干净，但考场上直接判 inst 位段最快。

### 排查速查表

| 症状 | 先查什么 |
|---|---|
| sbt elaborate 报 assert `replaced_mask.length == 32` | 编码掩码不是 32 位（多空格/少位） |
| elaborate 日志有 `already added encoding` Warning | 新编码与旧条目掩码完全相同，检查位串 |
| 新指令执行结果恒错但其他正常 | ALU 分支没命中：枚举名/译码 aluOp 是否一致；src1/src2 来源（useRj/useRk）是否配对 |
| 分支永远跳/永远不跳 | cmpOp 选错（有/无符号）；第二源是 rd 不是 rk |
| store 写入值不对 | store 数据来自 rd 字段，译码漏了 `useRd -> True` |
| load 地址偏了 4 倍 | 偏移格式是 si14<<2 却走了默认 si12（MemIssueQueuePlugin 没加特例） |
| 访存报 ALE 例外 | 对齐：WORD 需 4B 对齐，HALF 需 2B；lsType 选错 |
