## 2. 两大结构根源

### 根源 A：ROB pop 指针扇出锥（88/100 条路径的直接源头）

`popPtr[0]` 一拍之内驱动：
1. ROB RAM 读端口 → `CommitPlugin_regFlush` → `popCount`（`mycpu_top.v:180031` 的 3 级 mux 链）
2. pop 负载选择：8 条完成队列 × 32 窗口的 `validBits`/窗口 payload → `intResult`/`badVA`/`actualTaken` 等 32 位大 mux（`ROBFIFOPlugin_completionQueues_*`）
3. **跨模块广播**：同一拍还驱动 TLB 写使能（TLBIDX CE）、Rename 空闲列表回填 CE、ICache 回填地址、BTB PHT 更新地址 —— 整个 commit 广播都挂在组合的 popPtr 上。

典型 14 级路径（最坏 -5.470ns，到 `intResult_reg[21]`）：
```
popPtr[0] (fo=87)
→ LUT6 mem_i_98__9 → LUT6 mem_i_92__9 → LUT6 mem_i_71__11 (fo=248!)
→ LUT5 CommitPlugin_regFlush_i_2
→ LUT4 intResult[31]_i_18 (fo=111) → LUT6 except_code[3]_i_35 (fo=126) → LUT2 badVA[31]_i_46 (fo=148)
→ 跨入 completionQueues_1 窗口读 (when_ROBFIFOPlugin_l157)
→ LUT5 mispredict_i_136 → LUT4 intResult[31]_i_104 → validBits_26 → LUT5 intResult[31]_i_50 (fo=51)
→ 跨入 completionQueues_2 → LUT6 intResult[21]_i_11 → LUT5 i_5 → LUT5 i_2 → LUT3 i_1 → FF
```
数据路径 10.311ns：逻辑仅 1.849ns（17.9%），**布线 8.462ns（82.1%）**。物理跨度 X107Y133 → X131Y160 → X135Y177 → X125Y179，横跨大半个 die。所有 Top-100 路径的 route% 都在 80~88%。

### 根源 B：MEM1 TLB 查找 → 发射队列唤醒（15 级，独立于 A）

`MEMORY_ADDRESS_reg[17]` →(9级, CARRY4×2)→ TLB_LOOKUP_SNAPSHOT →(15级, MUXF7)→ IntIssueQueue 各队列 rRegs valid。访存地址生成 + TLB 命中比较 + 唤醒广播全在一拍。

## 3. 次要违例类

1. **异步复位 recovery**（上一轮布线数据）：`u_rst_cpu → LUT1 → mem_rstb`（fanout 6956，布线 6.3ns），WNS -2.708、**2983 个端点**。方法论报警 LUTAR-1（LUT 驱动异步复位）×8。
2. **MIG CDC hold**（QoR RQS_CLOCK-5_1）：ddr_clk→clk_pll_i、sys_clk→clk_pll_i 时钟拓扑不平衡，skew 高达 2.6ns，若干 hold 违例（xadc tempmon、AXI CDC FIFO）。属 MIG 内部路径，优先级低。
3. BRAM 未流水（RQS_TIMING-201）：ICache dataRAMs、BTB PHT 的 xpm 存储器。

## 5. 修复建议（按杠杆大小排序）

1. **ROB pop 负载输出寄存化**（最大杠杆，直接消掉 64+9+8+6+3≈90 条）：`fifoIO_pop_*_payload_state_*` 加一拍输出寄存器（SpinalHDL 中给 pop 流加 output register / `pipelined()`），commit 侧时序相应后移。这是 NOP 核 commit 接口的标准做法。
2. **popCount/regFlush 提前一拍**：payload mux 选择改用已存在的 `popCountReg`（`mycpu_top.v:180284`），斩断 popPtr→RAM→popCount→payload 串行链。
3. **commit 广播拆链**：TLB 写使能、freeList CE、ICache/BTB 地址这些"pop 负载派生"信号各自寄存一拍再分发；大扇出网（fo=248/148/126/111/87/51）配合 MAX_FANOUT 约束复制。
4. **发射队列唤醒路径**：TLB snapshot 输出或唤醒比较提前一拍。
5. **复位网络**：mem_rstb 改 BUFG 或按模块分散同步复位，消除 2983 个 recovery 端点。
6. 修完后重新 synth/impl（你正在跑的新流程），布线后重跑 `report_timing -nworst 100` 验证，并继续关注第 100 名以后的违例（TNS 表明后面还有大量路径）。
